## Access

DevourModMenu is a private project. The source code is not distributed.

Mod access is activated for users who support the project. Please contact me on Discord **before making any payment** so I can provide the current access and installation details.

Discord: `Jadis0x`

## Requirements

- Windows 10/11 (64-bit)
- A legitimate Steam copy of DEVOUR
- Microsoft Visual C++ Redistributable (x64)

## Installation

1. Copy the `DevourMenu.dll` file into the `Mods` folder in the DEVOUR directory.
2. Start DEVOUR through Steam. The menu will be available after your account has been activated.

Do not rename the DLL or modify the files supplied with your access. If the menu does not appear, contact me on Discord before reinstalling anything.
